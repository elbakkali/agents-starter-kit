# Architecture Decision Records

Short, durable records of significant technical choices.

## Format

Use [0000-template.md](0000-template.md). Number sequentially: `0001-`, `0002-`, …

## When to write an ADR

- New auth strategy, queue driver, or payment provider
- Breaking API or data model changes
- Security or compliance trade-offs
- Tooling choices that affect the whole team (PHPStan level, CI strategy)
